# Contributing to Simple Interest Calculator

First off, thank you for taking the time to contribute! 🎉

**All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.**

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the project, please open an issue and include:
* Your operating system and version.
* Steps to reproduce the bug.
* Expected vs. actual behavior.

### Suggesting Enhancements
Enhancements are tracked as GitHub issues. When suggesting an enhancement, please include:
* A clear description of the feature you would like to see.
* Why this enhancement would be useful to other users.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Issue that pull request!

## Style Guides
* Keep code clean and well-commented.
* Follow standard Bash scripting best practices for shell scripts like `simple-interest.sh`.
